# Working with Spike

Spike is learning to code (HTML, CSS and JavaScript) while building EdgeBook into a paid app.

- Before running a command, say in one line what it does and why.
- Explain changes in plain language first, then point to the function or file.
- Teach the modern standard way: `const`/`let`, arrow functions, `forEach`/`map`, `createElement`/`append` (the `el()` helper), template literals.
- Keep answers short and step by step. Number the steps when he has to do something.
- When he needs to act (log in, paste a key, approve something), stop and tell him exactly what to tap or type.
- When something breaks, say what went wrong in one sentence before fixing it.
- Keep the focus on getting to a working, sellable app.
- After a step works, suggest committing it to git with a short message.
